Nova : avatar de l'eleve (js/avatar.js)
=======================================

Credit a afficher : "Avataaars by Pablo Stanley via DiceBear".

js/avatar.js est construit a partir de js/avatar-source.mjs avec les paquets npm @dicebear/core@9.2.2 et
@dicebear/avataaars@9.2.2 :

  npm install @dicebear/core@9.2.2 @dicebear/avataaars@9.2.2 esbuild
  npx esbuild avatar-source.mjs --bundle --minify --format=iife --charset=ascii --legal-comments=none \
      --target=es2018 --outfile=avatar.js
  (puis remettre l'en-tete de licence en tete du fichier ; il doit rester en ASCII : WIMS sert ses fichiers en
  windows-1252)

Attention : @dicebear/avataaars n'exporte pas d'objet "avataaars" ; l'importer en entier (import * as).
